# Integrazioni reali necessarie

## Liv-ex

Serve per:

- prezzi mercato
- benchmark
- storico aste
- critic data
- bid/offer
- automazione trading per membri

Cosa fare:

1. Contattare Liv-ex
2. Richiedere membership/API
3. Ottenere credenziali
4. Configurare backend/.env
5. Adattare backend/src/connectors/livex.js

## Wine-Searcher

Possibile fonte per comparare prezzi.
Serve accesso commerciale o data feed.
Non usare scraping non autorizzato.

## Vinovest

Utile come piattaforma per gestione portafoglio.
Se non fornisce API pubblica, usare link sicuri o accordo partner.

## Cult Wines

Utile come advisor / piattaforma clienti.
Se non fornisce API pubblica, usare accordo business.

## Buy/Sell

Ordini reali solo con API ufficiali.
Mai automatizzare login o acquisti su siti terzi senza consenso.
